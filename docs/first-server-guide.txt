================================================================================
  Arma3 Server Tools — 首次开服指南（纯文本版，可用记事本打开）
================================================================================

本文说明从零配置并启动 Arma 3 专用服务器的推荐步骤。

--------------------------------------------------------------------------------
1. 环境要求
--------------------------------------------------------------------------------

  - Windows 10/11，安装路径与服务器目录均不能包含中文
  - .NET 10 Desktop Runtime（框架依赖发布时）
    下载: https://dotnet.microsoft.com/download/dotnet/10.0

--------------------------------------------------------------------------------
2. 获取程序
--------------------------------------------------------------------------------

  安装包: 运行 Arma3ServerTools-Setup.exe

  从源码构建:
    dotnet build Arma3ServerTools.sln -c Release
    主程序: src\Arma3ServerTools.App.WinForms\bin\Release\net10.0-windows\Arma3ServerTools.exe

--------------------------------------------------------------------------------
3. 安装专用服务器（SteamCMD）
--------------------------------------------------------------------------------

  【三种路径，不要混用】

  (1) 工具内置 SteamCMD
      - 点「下载 SteamCMD」解压到这里
      - 程序目录留空时使用
      - 典型: %LocalAppData%\Arma3ServerTools\extension\
        （安装到 Program Files 时）或 {程序目录}\extension\

  (2) SteamCMD 程序目录（设置页可填）
      - 含 steamcmd.exe 的文件夹
      - 模组会下载到其下的 steamapps\workshop\content\107410\<模组ID>\

  (3) 专用服务器游戏目录
      - arma3server、任务、server.cfg 等
      - 例如 D:\Games\Arma3Server\
      - 不是模组目录！

  【推荐步骤】

  1. 工具 → SteamCMD 设置，填 Steam 账号；程序目录可留空
  2. 点「下载 SteamCMD」（有进度条，请勿关闭窗口）
  3. 安装/更新专用服务器 → 选专用服务器游戏目录
  4. 模组页下载 Workshop 模组后，在模组下载目录下会出现对应 ID 文件夹

  【网络提示】
  若出现 502.3 / IIS / <!DOCTYPE，说明代理拦截了 Steam CDN，
  请关闭代理或手动解压完整 SteamCMD 到 extension 目录。

--------------------------------------------------------------------------------
4. 新建服务器配置
--------------------------------------------------------------------------------

  1. 服务器 → 新建，填配置名与服务器目录
  2. 设置页: 基本 / 安全 / 任务 / 模组 等
  3. 保存到工具 → 应用到服务器目录 → 启动

  说明 (v1.5+):
  - 保存到工具 → 只写 config\{uuid}\ 配置包 (manifest.json, mods.json 等)
  - 应用到服务器目录 → 写 server.cfg、basic.cfg、Profile、BattlEye 等
  - 启动 → 使用游戏目录已有 cfg，不会自动写 cfg
  - 在线说明: docs\config-workflow.md

--------------------------------------------------------------------------------
5. 监控与统计（可选）
--------------------------------------------------------------------------------

  统计页可启用 @a3st_monitor 与统计入库。
  需 Monitoring DLL，见仓库 docs\monitoring-cpp-dll-build.md

--------------------------------------------------------------------------------
6. 启动服务器
--------------------------------------------------------------------------------

  1. 已执行「应用到服务器目录」(启动前检查会验证 server.cfg)
  2. 点「启动」(会先把当前编辑保存到工具配置包)
  3. 远程控制页连接 RCon

--------------------------------------------------------------------------------
7. 封禁管理
--------------------------------------------------------------------------------

  封禁页: bans.txt
  远程控制: BattlEye 封禁

--------------------------------------------------------------------------------
8. 多服与复制
--------------------------------------------------------------------------------

  服务器 → 复制为新建，可快速建第二套配置。

--------------------------------------------------------------------------------
9. 常见问题
--------------------------------------------------------------------------------

  中文路径     → 移到纯英文路径
  RCon 失败    → 检查 BE、端口、密码、防火墙
  模组未出现   → 扫描路径含 steamapps\workshop\content\107410
  统计无数据   → 启用统计入库且 MonitoringHost 在运行

  在线 Markdown 版: https://github.com/ViVi141/arma3-server-tool/blob/main/docs/first-server-guide.md
