# UI 显示优化变更摘要

## 变更日期
2026年6月1日

## 变更概述
基于 UI 显示检查报告，完成了三项关键优化，改善用户界面在不同屏幕尺寸下的显示效果。

## 具体变更

### 1. 优化模组表格列宽分配
**文件**: `src/Arma3ServerTools.App.WinForms/Controls/ModSettingsPanel.cs`

**变更内容**:
| 列名 | 原宽度 | 新宽度 | 改进说明 |
|------|--------|--------|----------|
| 序号 | 4% | 3% | 序号列不需要太宽 |
| 文件夹名 | 9% | 12% | 增加 3%，显示完整 @mod 名称 |
| 模组名 | 13% | 15% | 增加 2%，显示较长的中文模组名 |
| Workshop ID | 8% | 7% | 减少 1%，ID 通常较短 |
| 签名状态 | 5% | 4% | 减少 1%，状态标识简短 |
| 路径 | 22% | 25% | 增加 3%，显示完整的长路径 |
| 更新时间 | 10% | 9% | 减少 1%，时间格式固定 |

**效果**:
- 长模组名称更容易完整显示
- 文件路径显示空间增加 13.6%
- 减少了文本被截断的情况

### 2. 降低窗口最小宽度
**文件**: `src/Arma3ServerTools.App.WinForms/MainForm.cs`

**变更内容**:
```csharp
// Before
MinimumSize = UiScaleHelper.ScaleSize(820, 560);

// After
MinimumSize = UiScaleHelper.ScaleSize(780, 560);
```

**效果**:
- 降低最小宽度 40 像素 (约 4.9%)
- 更好支持小屏幕设备 (如 1366x768 分辨率的笔记本)
- 在保持可用性的前提下提高了灵活性

### 3. 优化主窗口分隔比例
**文件**: `src/Arma3ServerTools.App.WinForms/MainForm.cs`

**变更内容**:
```csharp
// Before
SplitContainerHelper.BindProportionalSplit(split, 0.34, false, 240, 320);

// After
SplitContainerHelper.BindProportionalSplit(split, 0.30, false, 220, 340);
```

**变更说明**:
- 服务器列表区域: 34% → 30% (减少 4%)
- 设置面板区域: 66% → 70% (增加 4%)
- 左侧最小宽度: 240px → 220px
- 右侧最小宽度: 320px → 340px

**效果**:
在典型窗口尺寸 (1100px) 下:
- **Before**: 左侧 374px, 右侧 726px
- **After**: 左侧 330px, 右侧 770px
- 设置面板增加约 44px 宽度 (约 6%)，表单控件显示更宽松

1. **基础测试**: 在不同窗口尺寸下测试 UI 布局
2. **模组列表测试**: 添加长路径和长名称的模组，检查显示效果
3. **小屏幕测试**: 在 1366x768 分辨率下测试最小窗口尺寸
4. **分隔器测试**: 拖动主窗口分隔器，验证最小宽度限制
