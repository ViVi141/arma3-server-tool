单文件库 `ArmaMonitoringService.cs` 暴露一组由 RGiesecke.DllExport 导出的非托管入口（RVExtensionRegisterCallback / RVExtensionVersion / RVExtension / RVExtensionArgs），供 Arma3 的 SQF 脚本通过 callExtension 调用。所有导出函数均按 WIN64/WIN32 条件编译分别命名（x64 用无修饰名，x86 用 @N 修饰名）。RvExtensionArgs 是主入口：解析 args 数组后异步查找名为 "A3-Arma3ServerTools-ProcessCommunicationModule" 的窗口句柄，并通过 User32.dll 的 SendMessage + WM_COPYDATA 将数据块（含自定义签名 0x41335354）投递给宿主桌面应用，实现跨进程 IPC。项目目标为 Library，依赖 UnmanagedExports NuGet 包，构建配置区分 Debug/Release × x64/x86，并定义 WIN64/WIN32 常量以切换导出符号。
