根 package.json 通过 `workspaces: ["apps/*", "packages/*"]` 将四个子产物统一为单一 Node 工程：`packages/service`（Fastify + SQLite 后端）、`packages/web`（Vue 3 控制面板）、`packages/api-client`（TS API 客户端）、`apps/desktop`（Electron 壳），并通过 `scripts/` 下的 PowerShell 脚本串联构建、打包 APK、E2E 测试与冒烟测试；`.NET 4.8` 监控扩展位于仓库顶层 `DestinyServerMonitoring/`，作为独立 C# 项目由 CI 编译并随安装包分发。各子模块之间不直接引用源码，而是通过 `@a3st/api-client` 包与 HTTP REST API（端口 19580）进行跨进程通信，监控事件再由该扩展转发给桌面端进程。文档与 OpenClaw Skill 定义集中在 `docs/` 与 `skills/`，供 Agent 调用。
