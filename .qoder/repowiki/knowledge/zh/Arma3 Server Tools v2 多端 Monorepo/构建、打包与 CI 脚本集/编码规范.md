- 脚本统一以 `#Requires -Version 5.1` 开头，并将 `$ErrorActionPreference = "Stop"` 置于顶部以保证失败即终止。
- 通过 `$Root = Split-Path -Parent $PSScriptRoot` 定位仓库根目录后再 `Set-Location $Root`，使脚本可在任意工作目录下执行。
- 长流程编排使用本地 `Invoke-Step` 函数包装子步骤，统一打印 `==> <Name>` 前缀并以 `throw "Step failed: ... (exit $LASTEXITCODE)"` 报告失败。
- 对外部工具路径采用候选列表探测（如 Inno Setup 从 `INNO_SETUP_PATH`、`tools\innosetup-6`、`winget`、`Program Files` 等位置查找），找不到时给出带安装指引的错误信息。
- 关键中间产物均用 `Test-Path` 断言存在，缺失时抛出包含修复提示（如 `Run: npm run build:service`）的异常，而非静默继续。
- 需要临时目录的脚本在入口处先 `Remove-Item -Recurse -Force` 再 `New-Item` 重建，保证幂等重跑。
