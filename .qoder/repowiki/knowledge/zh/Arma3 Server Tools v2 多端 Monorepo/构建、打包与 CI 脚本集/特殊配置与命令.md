- 本地完整 CI：`powershell -ExecutionPolicy Bypass -File scripts/ci-local.ps1`（可通过 `A3ST_FORCE_NPM_CI=1` 强制重装依赖，`A3ST_SKIP_E2E=1` 跳过 Playwright）。
- 桌面构建：`scripts/build-desktop.ps1 [-SkipInstaller] [-DirOnly]`，需预先放置 `apps/desktop/build/icon.ico`。
- Windows 安装包：`scripts/build-release.ps1 [-Configuration Release|Debug] [-SelfContained] [-Version x.y.z] [-Zip] [-InstallInnoSetup]`，首次运行会自动尝试 winget 或下载 Inno Setup 6。
- Android APK：`scripts/pack-mobile-apk.ps1`，要求 `ANDROID_HOME` / `JAVA_HOME` 可用，且已通过 `npm -w @a3st/mobile exec -- cap add android` 初始化 Android 工程。
