模块由两个互不依赖的子目录组成：
- `docs/`：按主题组织的 Markdown 文档集合，以 `README.md` 作为索引，区分 v2（当前 TS/Electron/Capacitor 主线）与 v1（已移除源码的 WinForms 历史），并通过 `archive/releases/` 保存历史发版清单；Agent/OpenClaw 相关文档集中在 `agent-capabilities.md`、`agent-channels.md`、`openclaw-integration.md`、`deployment-ab-openclaw.md`、`ai-agent-pitfalls.md`。
- `skills/arma3-server-tools/SKILL.md`：OpenClaw Skill 描述文件，使用 YAML front-matter（`name`/`description`/`metadata.openclaw.requires.bins`/`primaryEnv`）声明技能元数据，正文是面向 AI 的调用手册，约定通过 PowerShell 脚本 `scripts/openclaw/a3st-invoke.ps1` 或直接 HTTP Bearer Token 访问 Agent API（端口 19580），并明确 PBO 上传、模组下载、任务 JSON、Inbox 等交互协议。
依赖方向单向：Skill 文档引用 `docs/` 下的部署与能力说明，反之不成立；两者均不引入代码依赖，仅作为仓库内可被安装到 `{app}\skills\` 或 `~/.openclaw/skills/` 的纯文本资产。
