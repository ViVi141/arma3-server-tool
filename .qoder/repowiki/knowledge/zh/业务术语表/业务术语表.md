### ConsoleShell
- 定义：v2 控制台的主导航壳层，采用 rail 模式导航 + 顶栏实例/操作条 + 子导航 Tab 布局，承载概览/部署/工坊/日志/配置/系统六大模式及 27 个视图页。
- 别名：控制台 Shell、shell

### ark 视觉主题
- 定义：ConsoleShell 的默认视觉主题，中性面 + 青色信号色风格，通过 `localStorage` 键 `a3st-visual-theme` 切换；另一主题是 classic（工具风）。
- 别名：ark 主题、ark visual theme

### classic 视觉主题
- 定义：ConsoleShell 的工具风视觉主题，保留 PROC/CFG 按钮组等传统布局密度，与 ark 主题并存。
- 别名：classic 主题、classic visual theme

### Rail 模式
- 定义：ConsoleShell 的导航模式：左侧 rail 列出 01~06 六大模式，右侧为子导航 Tab 与页面内容，区别于 VS Code 式三栏。
- 别名：rail 导航

### 开服机
- 定义：实际运行 Arma 3 专用服务器 + SteamCMD 的物理机器，可 Windows 或 Linux；Linux 场景通常只装 Service + 浏览器控制。
- 别名：server machine、host

### Service
- 定义：Node 被控端（`@a3st/service`），负责启停 arma3server、SteamCMD、RCon、日志、配置、监控统计等全部业务逻辑，对外暴露 Fastify REST API（默认 :19580）。
- 别名：后端服务、node service

### Web 壳层
- 定义：指 Electron 或 Capacitor 容器对 Vue 控制台 SPA 的宿主包装，本身不含业务逻辑，仅加载 web 静态资源并 spawn/连接 Service。
- 别名：壳层、shell

### Action
- 定义：Service 暴露的可执行操作项，权威列表通过 `GET /api/v1/actions` 获取，供 Web 控制台、OpenClaw Agent 等消费。
- 别名：actions

### BattlEye RCon V2
- 定义：Arma 3 BattlEye 的反作弊远程控制协议 v2，支持踢人、封禁、广播等操作，由 Service 通过 undici 调用。
- 别名：RCon、RCon V2

### RPT 日志
- 定义：Arma 3 运行时产生的 rpt 日志文件，Service 提供解析与管理能力，供控制台查看。
- 别名：rpt log

### Workshop 模组
- 定义：通过 Steam Workshop 下载的 Arma 3 模组，Service 提供下载、扫描、Bikey 复制等功能。
- 别名：mods、workshop mod

### SteamCMD
- 定义：Valve 的命令行 Steam 客户端，用于下载/更新 Arma 3 专用服务器与 Workshop 模组。
- 别名：steamcmd

### OpenClaw
- 定义：项目集成的 AI Agent 平台，通过 skills/arma3-server-tools 与 agent-capabilities/channels 文档定义的 Task action 格式调用 Service API。
- 别名：agent、AI Agent

### n100
- 定义：项目中特指的 x86 小主机（Intel N100），作为典型 Linux 开服机部署示例，仅运行 Service + 浏览器控制。
- 别名：N100

### v1
- 定义：基于 C# / WinForms 的原版 Arma3 Server Tools（destiny studio 出品），已迁移至 docs/archive/ 归档，源码已从仓库移除；v2 是其 TypeScript 全栈重构版本。
- 别名：WinForms 原版、旧版

### v2
- 定义：Arma3 Server Tools 的 TypeScript 全栈主线版本（当前 2.0.0-alpha），采用 Vue 3 + Electron + Node/Fastify 架构，替换原 v1 WinForms。
- 别名：新版
